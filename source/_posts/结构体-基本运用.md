# 结构体的定义

我们使用`struct`来定义结构体，格式如下

```cpp
struct 结构体名字{
  类型名 变量名
};
```

例如我们定义一个坐标结构体：

```cpp
struct zuobiao{
  int x,y;
};
```

# 结构体的使用

我们可以直接像`int`那样定义结构体变量和数组。

```cpp
zuobiao tr;
```

我们用`.`操作符来访问结构体的元素。

```cpp
zuobiao tr;
tr.x=100,tr.y=-100;
```

结构体的初始化可以用`{}`来初始化，对顺序有严格要求（按照你定义的顺序）

```cpp
zuobiao tr={100,-100};//x=100,y=-100
```

# 结构体的其他妙用

我们用结构体排序时，可以写cmp函数：

```cpp
#include <bits/stdc++.h>
using namespace std;
struct ren{
	int qian;
	string ming;
};
bool cmp(ren x,ren y){//前一个元素大于后一个返回1（降序）
	return x.qian>y.qian;
}
int main(){
	ren a[105];
	int n;
	cin>>n;
	for(int i=1;i<=n;i++){
		cin>>a[i].ming>>a[i].qian;
	}
	sort(a+1,a+n+1,cmp);
	for(int i=1;i<=n;i++){
		cout<<a[i].ming<<' '<<a[i].qian<<endl;
	}
	return 0;
}
```
